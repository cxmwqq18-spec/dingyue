内链目录模块 · UI 设计 v2（3 个方案）

位置不变：视频 hub 分页器下方、CTA 按钮上方。三个方案都是纯 SSR + 纯 CSS（hover 为 CSS 实现），链接数据用当前线上真实数据。仅为预览，未动任何线上代码。

上一版被否的原因，本版针对性修正：① 每个链接带图标 + 箭头太吵 → 全部去掉（方案 C 只给每组一个图标）；② 卡片盒子感重、三块等大很呆 → 方案 A/B 无盒子或极轻；③ 长标签被截断（"Beauty & Pe…"）→ 本版所有方案都不截断。

方案 A · 药丸标签组最轻量

组标题 + 圆角标签自然换行。信息密度最高、高度最矮，和上方视频卡片区衔接最顺；「All industries / All platforms / All occasions」用品牌渐变实底做视觉锚点，用户一眼找到「全部」入口。

方案 B · 精致分栏编辑风 · 推荐

保留现在「分栏 + 下划线链接」的骨架（改动观感最小），但去掉下划线、改成分隔线列表：行高舒展、永不截断，hover 时整行右移并出现紫色箭头。顶部一条细分割线与分页器区分。最像正式站点的 footer 导航 / 目录页质感。

方案 C · 一体化目录面板面板感

一个圆角大面板包住三组，组和组之间用竖分隔线；每组只有一个图标（行业=标签、平台=喇叭、场景=日历），链接内部两列排布、hover 变紫。比上一版安静得多，但保留了「这是一个完整模块」的分量感。手机上自动变单组堆叠。

三个方案对比：A 最矮最轻（约 260px 高），适合把注意力留给上面的视频卡片；B 无盒子、编辑质感，观感改动最小但精致度提升明显；C 模块感最强，适合想让它成为页面「目录枢纽」的定位。
共同点：全部链接不截断；无逐链接图标/箭头；hover 只做颜色/位移反馈；纯 CSS 无脚本；actors 页和工具页的同一类模块会复用同一套样式（组数随数据自适应）。
选哪个？回复 A / B / C 即可；也可以混搭（比如 B 的分栏 + A 的渐变「All」标签），或指出想调整的细节（颜色、密度、是否要图标等）。
