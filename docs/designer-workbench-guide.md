# 装修器文案修改教程

这份教程面向运营和后台配置人员，目标是把“看到一句文案”到“知道去哪里改”这件事固定成一条稳定流程。

## 1. 先认识工作台

进入“店铺装修”后，页面分成三块：

- 中间：前台预览。鼠标移到页面区域，会显示当前区域是否可编辑；点击模块后，右侧会自动定位。
- 右侧上方：三个固定入口，分别是“当前页面”“全局页头/页脚”“发布检查”。
- 右侧下方：结构树和属性面板。左侧树负责选对象，右侧字段负责改内容。

顶部命令栏按四组工作：

- 查看：刷新预览、切换实时预览。
- 编辑：保存草稿、回滚到线上版本。
- 发布：打开发布确认，不会直接误发布。
- 退出：打开主题库、前台或退出后台。

## 2. 先判断文案来源

装修器里的文案来源分为五类：

- 当前页面：页面主体模块里的标题、按钮、卡片、FAQ 等字段。
- 全局配置：全站共用的 Header、Footer、品牌、颜色、字体等字段。
- 导航菜单：页眉导航和页脚导航链接。
- SEO：站点标题、默认描述、分享图和 robots 默认项。
- 代码硬编码：当前还没有进入后台配置的数据，只能查看，需要开发迁移成字段后再让运营配置。

右侧的“文案定位器”可以直接搜索预览里看到的文字，并显示来源标签。

## 3. 标准操作流程

1. 选择页面：在左侧页面目录或顶部页面菜单选择要修改的页面。
2. 定位文案：在文案定位器输入预览中看到的文字。
3. 进入字段：点击搜索结果，右侧会跳到对应页面模块、全局 Header/Footer、导航或 SEO 字段。
4. 保存草稿：保存只写入后台草稿区，不会影响线上。
5. 发布上线：发布会更新整站线上快照，当前页面、隐藏草稿页和全局设置会一起上线。

## 4. 常见修改路径

- 改 Logo：进入“全局页头/页脚”，找到 Logo 或品牌字段。
- 改导航：点击“编辑导航”，维护页眉导航和页脚导航链接。
- 改首页 Hero：选择首页，搜索首屏主标题，进入当前页面模块字段。
- 改 Footer 公司信息：搜索公司名、地址、邮箱或 `Company`，进入全局页脚字段。
- 改 SEO 标题：点击“编辑 SEO”，修改默认站点标题或描述。
- 登录页没有模块：登录页主体可能是 0 模块，但预览里仍会显示全局页头和页脚，应去全局配置修改。

## 5. 草稿、线上快照和部署

- 保存草稿不会上线：它只更新 `ThemePage.draftJson` 和 `ThemeSettings.draftJson`。
- 发布才会上线：发布会把草稿写入 `publishedJson`，前台读取线上快照。
- 代码部署不会自动覆盖文案：代码上线只改变渲染逻辑，数据库里的已发布内容不会自动改掉。
- 整站发布仍是单次快照：v1 不拆单页发布，发布确认里会列出一起上线的范围。

## 6. 发布前怎么确认

点击“发布”后，不要直接猜范围，先看确认窗口：

- 会一起上线的页面数量。
- 隐藏草稿数量。
- 全局设置是否有变更。
- 当前线上版本和发布记录。

确认无误后再点“确认发布”。发布按钮处理中会锁定，避免重复提交。

## 7. 409 冲突怎么处理

如果保存或发布时出现 409，说明你确认时看到的草稿版本、全局设置版本或线上版本已经被别的操作改过。

处理方式：

1. 刷新装修器。
2. 重新检查当前页面、全局 Header/Footer、导航和 SEO。
3. 再保存草稿。
4. 确认发布范围后重新发布。

不要在 409 后强行覆盖，因为这可能把别人刚保存的文案静默覆盖掉。

## 8. 页面打不开或显示 network error

1. 点击错误页里的“重试”。
2. 重新登录站点后台。
3. 如果装修器能打开但资源加载失败，先继续修改页面文案；资源字段失败不会自动覆盖已保存草稿。
4. 如果持续失败，把错误编号、页面路径和发生时间交给开发检查服务日志与 Prisma migration。

## 9. 字段迁移规则

如果定位器显示“代码硬编码”，说明这句文案暂时不能在后台直接改。开发需要先做一层内容契约：

- 新增可配置字段，保持旧字段兼容。
- 对旧快照做迁移或兼容别名。
- 确认旧发布快照在当前 renderer 下仍可正常渲染。
- 再交给运营通过装修器维护。
