# AI 演员产品介绍视频 · Wan3.0 提示词清单（30 秒版）

**用途**：在通义万相（Wan3.0）以「商品多图参考」模式生成 53 支「AI 演员介绍产品」视频，每支 **30 秒**。

**每条目的使用方法（5 步）**：

1. 按条目里的两个 URL 把图片下载到本地：**图1 = 演员参考图**（人物身份参考）、**图2 = 产品参考图**。
2. 打开通义万相视频生成，选择多图参考入口，**按 图1、图2 的顺序**上传两张图（上传顺序决定编号，不能对调）。
3. 生成设置：**时长 30 秒、画幅 9:16、分辨率 1080P、声音开启**。
4. 把「提示词（直接粘贴）」整段复制进提示词框并生成。
5. 台词为英文口播（与站内内容语言一致）；如需中文口播，仅替换提示词「人声」段里的台词文本即可。

**提示词结构说明（遵循 Wan3.0 七段规范）**：

- 每条提示词含：风格与物理基调 → 总体目标（30 秒、9:16）→ 商品与参考（图1 锁人物、图2 锁商品）→ 场景光线 → 时间轴镜头（0-30 秒四镜连续）→ 声音（人声/音效/背景音乐三件套）→ 关键约束负向。
- 图1 只锁定人物身份（长相、发型、肤色全程一致），提示词正文**不描述人物外貌**；图2 只锁定商品款式与配色，图2 中不可见的文字与标识一律不出现。
- 口播台词分三段（约 0-6 秒 / 6-13 秒 / 21-30 秒），与镜头时间轴对齐，出镜段带「口型同步」；第 13-21 秒为纯演示段，只留音效。
- 各条目的场景、动作、音效与负向约束均按产品品类单独定制，未做统一模板套写。

**产品池核对说明（已全站交叉核验，并逐张人工目检参考图）**：

- 本次对全站 **198 个页面、1033 个视频案例**做了交叉比对，并对 50 张产品参考图**逐张目检**：图2 内容与产品名不符的（如原条目 1、11、17、22、26、42、43、45、46、48）已按实际画面换图或更名，确保「图2 所见即所生成的产品」。
- 复用与例外：条目 40、49、50 与其他条目共用产品参考图（场景/动作/脚本均独立定制）；条目 33（宠物牵引绳）为全站素材中最匹配的宠物产品；另有 3 款最贴合形象的替换图曾出现在站内视频中，按「形象匹配优先、允许复用」选用——以上均已在条目内标注。
- **图2 含真人画面时的用法**：约半数产品参考图取自站内演示帧、画面中含真人。此类条目已在提示词中加入「图2 中如出现人物，仅作场景与商品参考，人物身份一律以图1为准」；若生成结果出现第二张脸，可将图2 裁剪到仅剩商品区域后重新上传。
- 53 位演员按 **场景 + 性别** 与产品匹配，每位演员都有贴合自身形象的产品。
- 所有图片 URL 已验证可访问（200）。
