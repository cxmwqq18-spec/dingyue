# AIVideosUGC 技术说明书（给后端技术）— 2026-10-12

## 1. 先看这个：为什么要补后端
- 网站 www.aivideosugc.com 的公开页（80 页）已经按竞品 tagshop.ai 的写法改完并上线。
- 老板定的规矩：竞品有、我们还没有的功能，**页面上一律写成已经有**（不写 coming soon），由技术补齐。所以现在页面承诺的功能，有一批后端还没做，客户点进工作台会发现做不到。
- 你的任务：按第 3 节的清单把功能做出来，做完一项按「验收」自测，再告诉老板。
- 逐项明细（代码位置、竞品写法、页面提到几次）：`交接/后端待补功能清单-2026-10-12.md`。本说明书是它的使用说明和优先级。

## 2. 代码在哪、页面怎么来的
- 仓库：`github.com/cxmwqq18-spec/dingyue`，主分支 `main`（线上版本 = main 最新提交）。只看 AIVideosUGC（站点 id `site_aidreamcapes`）相关代码；同仓库里的 MyDreamShoots 站不要动。
- 公开页的文字和图片引用全在数据文件里，不在组件里：
  - 每页一个 JSON：`scripts/data/aidreamcapes-site-v2/content/<页>.json`
  - 页面目录、主关键词：`scripts/data/aidreamcapes-site-v2/master.json`；图片登记：`media-catalog.json`
  - 组装逻辑：`scripts/lib/aidreamcapes-site-v2-content.mjs`；渲染组件：`src/components/storefront/aidreamcapes-v2/`
  - 页面内容存在数据库里，由迁移脚本 `scripts/migrate-aidreamcapes-site-v2.mjs` 写入（线上程序从库里读内容）。
- 工作台（客户真正生成图和视频的地方）：
  - 下单与任务：`src/lib/stores/job-store.ts`、`src/components/app/job-create-form.tsx`、`src/components/storefront/customer-workspace-shell.tsx`
  - 生成调度：`src/app/api/internal/ai-worker/dispatch/route.ts`
  - 时长与画幅：`src/lib/aidreamcapes-create-intent.ts`、`src/lib/video-frame-config.ts`
  - 链接导入：`src/lib/product-url-import.ts`
- 公开页按钮带参数进工作台（如 `tool=white-background`、`tool=change-background`、`tool=model-photos`、`tool=lifestyle-photos`），**这些参数目前在工作台里被丢掉了**（见清单第 23 条），接功能时要接上。

## 4. 定价和积分（页面写死的真数，后端扣费要一致）
- Starter $24.50/月 200 积分；Pro $35/月 300 积分；Premium $63/月 600 积分。
- 视频 6/10/15/30 秒 = 24/40/60/120 积分；一张图 24 积分；生成失败退回积分；下载无水印、可商用。
- 改价格或积分规则前先找老板，页面要同步改。

## 5. 改完怎么上线（避免今天的事故）
- 走现有发布流程：本机检查（站点校验 0 错、本机迁库、本机冒烟）→ 上传新图片 → 迁内容 → 部署 → 线上检查。服务器空间少于 30G 先清旧版本（只留 3 个）。
- **代码和数据结构一起变的改动，代码必须先于或同时于内容上线。** 10-12 22:07–22:33 首页报 500：新内容先进了线上库，新代码没部署上，旧代码读新数据就崩了。
- 发布失败后，先清掉服务器上同名的失败版本目录（核过不是当前在用的），再重发。
- 新图片要在部署前传到服务器；不要在图片上线前访问它的网址（Cloudflare 会把 404 缓存一年）。
- 公开页一律不能加 noindex。
- 生产服务器的访问方式、数据库账号找老板要，不写在仓库里。
