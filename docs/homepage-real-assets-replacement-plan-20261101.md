## 二、替换原则

1. **真实优先**：所有示意位换用真实生成资产（演员成片帧/肖像/产品参考图），不再用旧 mockup。
2. **语义对位**：模块文案讲什么，图就放什么——"产品照片→AI 视频"模块用「产品参考图 → 演员视频帧」前后对；"AI 主持人"模块用真实演员肖像；场景预览用演员案例卡。
3. **一次抽帧、多处复用**：用 ffmpeg 从 53 条成片抽取统一规格帧（竖版 1080×1920 一帧 + 横版 1920×1080 一帧），命名 `<actorSlug>-frame-<v|h>.jpg`，入 `public-media/image/`。
4. **文案同步**：模块标题/描述改写为真实产品与演员叙事（对照 md 文档的产品名与场景名），保留 SEO 关键词（"AI 产品视频"、"UGC"、"产品演示视频" 等词不丢）。
5. **首页 picker 不动**：20 张演员案例卡刚上线，本方案不改它。

## 五、风险与边界

| 风险 | 评估 | 缓解 |
|---|---|---|
| 首页 SEO 关键词丢失 | 中——主标题"将产品照片转换为人工智能视频和图像"及模块 H2 含核心词 | 文案改写保留核心词；P4 加关键词存在性检查 |
| 图文不匹配（新图讲的是别的产品） | 中——映射表人工确认 | 每模块的图与文案取自**同一条目**，映射表 P0 逐条过目 |
| 视频抽帧质量（运动模糊帧） | 低——抽帧位置可指定（取每条视频 3s/15s 处清晰帧） | 抽帧脚本带时间点参数，抽后人工抽检 |
| 演员肖像版权/一致性 | 低——全部为站内自产演员 | 仅用站内资产 |
| 首页缓存 | 低——重启清进程缓存 + CDN s-maxage 300 | 同既有流程 |
| 旧模版图被其它页引用 | 需检查——若其它页面也用这些文件，首页替换**不影响**其它页（文件不删） | 只改首页数据，文件保留 |
