# Native Style System Notes — Save the Date

## Direction
Elegant editorial Save the Date video scene photography with a dark, warm interface. The page should feel modern, romantic, and wedding-adjacent while remaining distinct from an invitation-template gallery.

## Palette
- Ink: #0B0D12
- Night: #151822
- Ivory: #F7F3ED
- Champagne: #D9AF68
- Rose: #C85D78
- Warm gray: #A8A3A0
- Success: #6FC2A0

## Typography
Use the live site's shared font stack. The prototype uses Georgia for editorial headings and Inter/system sans for interface text. Do not ship custom font files in the package.

## Imagery
- People remain the visual subject.
- Warm light, natural expressions, and restrained wedding context.
- No text baked into formal source images.
- No UI mockups, screenshots, contact sheets, or collages inside `/images/`.
- Review faces, eyes, hair, hands, fingers, rings, earrings, shoulder straps, contact points, reflections, and background edges at full size.

## Layout
- Desktop hero: copy left, dominant couple image right, two supporting Hero images below.
- Mobile hero: H1 first, primary image second, CTAs before long copy.
- Content sections alternate explanatory copy and formal imagery to keep the page editorial rather than card-heavy.
- Image captions stay near the relevant copy; filenames and alt text remain descriptive, not promotional.
