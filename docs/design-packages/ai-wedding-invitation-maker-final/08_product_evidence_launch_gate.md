# Product Evidence Launch Gate

**Indexation status: HOLD until verified.**

Verify before launch:
- Actual input path and supported invitation fields.
- Whether users can edit names, date, venue, RSVP and links.
- Supported output types and print/export behavior.
- Pricing / credit behavior.
- Privacy handling for uploaded photos or wedding information.
- Watermark behavior.
- Commercial-use / print-use rights language.
- Live CTA destination.

Do not publish unsupported claims such as **free**, **unlimited**, **one-click**, **no watermark**, **100% private**, **commercial rights included**, or **instant** without approved evidence.
