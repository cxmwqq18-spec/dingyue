# Native Style System Notes

- Reference family: current myDreamshoots dark topic-page system shown in the user-provided TikTok page screenshot.
- Goal: same theme family, not a pixel-for-pixel copy.
- Base background: near-black/navy.
- Cards: slightly lighter charcoal with subtle borders and 16–20px radii.
- Accent: violet/purple for badges, CTAs and small eyebrow labels.
- Pacing sections: occasional pale lavender content band to break up long dark-page rhythm.
- Typography: bold, compact white headings; muted gray body copy; restrained line length.
- Images: large real-scene wedding/invitation photography. Formal `images/` never contains page screenshots, contact sheets or mockups.
- Wedding Invitation intent: invitation maker / generator, not Wedding Invitation Video, Proposal, Engagement, or Save the Date.
- Critical wedding facts (names, dates, venue, RSVP, URLs): use editable HTML/product fields after visual approval; do not rely on AI-image text.
