这版如何对应参考站

参考站的版式本版对应
大标题 + 说明 + 单一主按钮，右侧效果组合图移除上一版首屏的设置表单，改为左文右图；原图与结果使用本站实际商品资源。
居中板块标题 + 四组交替图文采用相同的阅读顺序与留白节奏，功能文案排在图片外，逐组提供制作入口。
三步说明 + 案例 + FAQ + 居中结尾入口两页共用这些模块，替换对应内容；相关工具与页脚使用本站有效内链。
参考站白底与紫色按钮按你的要求替换为本站星空黑底、深紫色微光、白色标题和紫粉蓝渐变按钮。白色只作为商品照片内部的原有背景。

首屏和图文区采用本站原有标题、说明和图片，步骤及 FAQ 保持与实际工作台流程一致。案例为示例场景，不冒充客户评价。

统一模板与页面数据

Header → Breadcrumb → Hero → Overview → FeatureRows × 4 → Steps × 3 → Examples × 3 → FAQ → RelatedTools → CTA → Footer

两页都由同一个 build_design.py 模板生成，页面字段统一保存在 page-data.json。这份 JSON 仅属于离线 UI 评审，正式页面仍须从当前 site_aidreamcapes 的 LivePage.contentJson 完整 SSR，不用此文件回填线上数据。

交互与跳转

  • 导航、Logo、面包屑、相关工具与页脚：标准站内链接，同标签页打开。
  • 所有制作按钮：进入当前页面对应的图片工作台；白底图携带 white-background，社交图片携带 lifestyle-photos，以及合法比例和场景提示；不自动生成或扣费。
  • See examples：滚动至本页案例区。案例为展示内容，制作入口统一进入本页工具。
  • 访客可进入完整工作台；保存或生成按现有流程登录，返回当前工作台。保留现有访客草稿恢复逻辑，不在 URL 中传递私有图片。
  • FAQ：原生折叠，键盘可操作；手机端导航折叠成菜单。
  • 公开页面不请求私有 API；上传、费用报价、生成与下载均在工作台处理。
  • 这一版公开页面不设置外部跳转；下方竞品链接只供设计评审，不加入正式导航。
