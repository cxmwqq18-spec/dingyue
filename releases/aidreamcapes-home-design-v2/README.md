# AIVideosUGC 首页视觉设计稿 V2

状态：**仅供审阅的静态设计图**。没有接入首页、修改前端组件或变更订阅数据。

## 页面叙事

1. **我们做什么**：从产品照片、链接或创意，制作产品视频、UGC 风格广告和商品图片。
2. **怎么操作**：上传素材 → 选择场景模版 → 写清创意简报 → 核对费用与结果 → 保存或调整。
3. **可以看到什么**：用 Aidreamcapes 已有的护肤品、香薰和鞋类素材，展示“原图 → 场景方向”的图文示例。示例标为概念画面，不暗示已经生成了可播放视频。
4. **适合谁**：电商品牌、小型团队、营销与代理团队、内容创作者。
5. **价值**：围绕同一产品探索不同讲法，为详情页、社交帖文和短视频准备素材；实际业务效果取决于素材、审核与投放。

## 模块保留与新增

- **保留展示**：导航、场景模版、工作原理、功能优势、工具入口、适用人群、价格、对比、信任信息、FAQ 和最终行动入口。
- **新增设计**：首屏“商品 → 多场景”视觉构图、产品定位卡、四步工作台演示、三组原图与场景对照、内容用途演示。
- 价格仅在图稿中示意当前月付信息；真实金额、年付选项、积分和结算状态仍应由当前关系数据决定。
